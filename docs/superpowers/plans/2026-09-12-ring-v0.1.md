# RING v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add one bounded resonant-propagation specimen proving that attributable history can change which already-lawful musical transform becomes eligible next without changing source evidence, proposal authority, or renderer authority.

**Architecture:** RING is an opt-in proposal-side cavity beside the existing Specimen 001 pipeline. It consumes the existing `haunted-phonograph/score/v1`, seed, observations, and optionally an already-admitted HAUNT influence plan; it exposes exactly three musical relations and propagates a deterministic susceptibility field for at most four steps. RING produces a trace plus a mutation-result-shaped final musical state, then reuses the existing `resolvePerformance()` membrane and binds trace/performance identities into a RING receipt. Existing `mutateScore()`, HAUNT, and the normal specimen runner remain unchanged.

**Tech Stack:** Node.js ESM, built-in `node:test`, existing `hashCanonical`, `mutateScore`, `resolvePerformance`, `createHauntCapsule`, and `buildHauntInfluencePlan` contracts.

**Spec:** `docs/2026-08-23-cross-pollination-history-shaped-musical-possibility.md` and GitHub issue #10 (`Specimen 002 — RING v0.1`).

## Global Constraints

- Exactly three declared transform relations: `interval-displacement`, `rhythmic-stretch`, `dynamic-bloom`.
- One four-note motif is sufficient for v0.1.
- RING may alter proposal-side susceptibility and realized musical state; it may not alter source evidence, uncertainty, proposal authority, renderer/export authority, or constitutional authority.
- Maximum propagation length is four steps.
- No hidden entropy; identical inputs must reproduce trace, refusals, terminal state, performance, and receipt identities.
- No wall-clock decay. Susceptibility changes only through deterministic causal propagation steps.
- HAUNT may contribute attributable `late-bloom` pressure only through an already-valid influence plan; raw capsules do not enter RING.
- No-HAUNT/no-history RING must damp after the already-lawful interval displacement and preserve the prior musical behavior shape: same displaced pitches, same durations, uniform velocity.
- RING must not modify `src/mutation.mjs`, `src/performance.mjs`, `src/haunt-*.mjs`, `src/receipt.mjs`, or `src/run-specimen.mjs`.
- `ResolvedPerformance` remains the renderer/export membrane.
- Do not build a transform registry, graph runtime, harmonic engine, catalog cavity, reprise system, or self-witness loop in v0.1.

## Frozen susceptibility model

Use integer units to avoid incidental floating-point state:

```text
threshold = 10

initial:
  interval-displacement = 10
  rhythmic-stretch      = 4
  dynamic-bloom         = 3

late-bloom history residue:
  dynamic-bloom += 10

when dynamic-bloom fires:
  dynamic-bloom = 0
  interval-displacement += 5
  rhythmic-stretch += 3

when interval-displacement fires:
  interval-displacement = 0
  rhythmic-stretch += 4

when rhythmic-stretch fires:
  rhythmic-stretch = 0
```

Selection rule:

```text
eligible = unvisited relations with susceptibility >= 10
choose highest susceptibility
break ties by frozen relation order:
  interval-displacement
  rhythmic-stretch
  dynamic-bloom
```

Therefore the first hostile pair is deterministic:

```text
NO HISTORY
  initial = {10,4,3}
  interval-displacement fires
  after   = {0,8,3}
  nothing remains eligible
  terminal = damped

LATE-BLOOM HISTORY
  initial = {10,4,13}
  dynamic-bloom fires
  after   = {15,7,0}
  interval-displacement fires
  after   = {0,11,0}
  rhythmic-stretch fires
  after   = {0,0,0}
  terminal = completed
```

Transform realizations:

```text
interval-displacement:
  reuse mutateScore({ score, seed }) and take its selectedOffset + pitches

rhythmic-stretch:
  durationsQuarter = durationsQuarter * 1.5

 dynamic-bloom:
  velocityProfile = [56, 64, 88, 108]
```

The dynamic profile deliberately reuses the already-landed HAUNT late-bloom contour rather than inventing a second meaning for `late-bloom`.
