# FIELD ANSWER 001 — A Bounded Musical Reply Without Pretending to Understand the Song

## Claim

Haunted Phonograph can now accept the exact canonical WAV from a First-Listen Radio window and return one deterministic playable musical proposal with a receipt that keeps signal evidence separate from invented music.

The aperture is intentionally narrow:

source window bytes
→ exact digest verification
→ bounded PCM signal facts
→ proposal-only musical object
→ resolved performance
→ MIDI + WAV audition
→ receipt

## Evidence floor

FIELD ANSWER 001 measures only facts available directly from the canonical PCM carrier:

- frame count;
- duration;
- four-quarter RMS energy contour;
- peak amplitude;
- zero-crossing activity.

Those facts enter provenance as evidence under:

canonical-pcm-signal-profile/v0

The analyzer does not claim:

- tempo of the source;
- pitch or key of the source;
- chords;
- motifs;
- lyrics;
- instrumentation;
- emotional meaning;
- author intent.

SIGNAL FACT != MUSICAL MEANING

## Proposal

The signal profile influences a four-event answer proposal.

Energy contour affects interval direction and duration pressure. Zero-crossing activity influences the proposal tempo range. Exact source identity plus the explicit deterministic seed resolves remaining choices.

Every resulting pitch, duration, velocity, tempo, and synthesis decision remains proposal authority.

PROPOSAL != SOURCE EVIDENCE

DIGEST-SEEDED CHOICE != HEARD PITCH

The answer is therefore a lawful musical response to the bounded signal, not a claim that the Phonograph transcribed or semantically understood the window.

## Playable projections

The result emits:

- Standard MIDI File;
- deterministic stereo PCM WAV audition.

The audition uses a deliberately simple sine-plus-second-harmonic renderer. It is a projection of the resolved proposal, not a canonical timbre claim.

AUDITION != ADMISSION

RESPONSE != REMIX

## Receipt

The field-answer receipt binds:

- source window id;
- canonical audio SHA-256;
- parent source SHA-256;
- requested bounds;
- exact duration;
- signal-evidence hash;
- proposal hash;
- resolved-performance hash;
- deterministic seed;
- MIDI hash/length;
- audition WAV hash/length;
- renderer identity.

The returned result does not carry the source WAV bytes forward.

## Relationship to the Field Station

This aperture is suitable for a read-only Field Station door only when the local Haunted Phonograph checkout actually contains the FIELD ANSWER executable.

Repository presence by itself remains insufficient.

REPOSITORY PRESENT != CAPABILITY AVAILABLE

A future House crossing may explicitly ask Phonograph for a proposal. That proposal remains local and reversible until a human admits some consequence.

FIELD ANSWER != HOUSE CROSSING

MUSICAL POSSIBILITY != RECOMMENDATION
